# OshRest — места отдыха Ошской области

Один проект, **три сайта** (все устанавливаются как приложения — PWA):

| Сайт | Адрес | Для кого |
|---|---|---|
| Туристы | `https://ВАШ-САЙТ.onrender.com/` | Регистрация и вход, поиск, карта, избранное, бронь или вопрос администратору. После входа повторно вводить пароль не нужно — до нажатия «Выйти». |
| Администраторы объектов | `…/owner/` | Только вход (без регистрации). Заявки приходят сверху в реальном времени. Сами добавляют объект, номера, цены, услуги, фото. |
| Главный администратор | `…/admin/` | Видит и управляет всей базой: создаёт логины/пароли владельцам, назначает объекты, видит статистику, туристов, заявки. Запросы «забыл пароль» приходят сюда. |

Стек: статические файлы + маленький Node-сервер (без зависимостей) на **Render**, база/вход/файлы/realtime — **Supabase**, код — **GitHub**.

## Запуск за 4 шага

### 1. Supabase
1. Создайте проект на supabase.com.
2. **SQL Editor** → вставьте и выполните `supabase/schema.sql`.
3. Затем выполните `supabase/seed.sql` (12 демо-объектов и 29 номеров из шаблона).
4. **Authentication → Providers → Email**: выключите «Confirm email» (аккаунты создаёт сервер сам).
5. **Project Settings → API**: скопируйте `Project URL`, `anon/publishable key` и `service_role key` (секретный!).

### 2. GitHub
Создайте репозиторий и загрузите содержимое папки `oshrest/` (файл `.env` не загружайте — он в `.gitignore`).

### 3. Render
1. **New → Web Service** → ваш репозиторий (или Blueprint — есть `render.yaml`).
2. Build Command: *(пусто)*, Start Command: `node server.js`.
3. **Environment**:

| Переменная | Значение |
|---|---|
| `SUPABASE_URL` | Project URL |
| `SUPABASE_ANON_KEY` | anon/publishable key |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key (только здесь, на сервере!) |
| `ADMIN_LOGIN` | логин главного админа (например `admin` или ваш e-mail) |
| `ADMIN_PASSWORD` | пароль главного админа |
| `RESEND_API_KEY`, `ADMIN_NOTIFY_EMAIL` | *необязательно*: письмо главному админу при «забыл пароль» |

При старте сервер сам создаёт главного администратора. Сменить его пароль = изменить `ADMIN_PASSWORD` и перезапустить.

### 4. Первый вход
1. Откройте `/admin/` → войдите → вкладка **Админы** → создайте логин/пароль для владельца объекта (данные можно сразу отправить в WhatsApp).
2. Вкладка **Объекты** → назначьте демо-объекты владельцам (или владельцы добавят свои сами).
3. Туристы регистрируются на главной странице (телефон или e-mail).

## Как это работает
- **Роли** хранятся в `profiles.role` (`tourist` / `owner` / `admin`). Роль задаёт только сервер (`app_metadata`), поэтому турист не может сделать себя владельцем.
- **Безопасность на уровне базы (RLS)**: турист видит только свои заявки; владелец — только заявки своих объектов и правит только свои объекты; полный доступ — только у главного админа.
- **Цена брони считается на сервере** (триггер в БД), подделать её с телефона нельзя; занятые даты блокируются автоматически.
- **Уведомления**: новая заявка появляется у владельца сверху мгновенно (Supabase Realtime) + звук, вибрация, счётчик на вкладке; если realtime недоступен — опрос каждые 45 сек. Ответ владельца/подтверждение так же мгновенно приходит туристу.
- **Забыл пароль (владелец)**: заявка попадает на вкладку «Пароли» главного админа (и на e-mail, если настроен Resend); админ задаёт новый пароль в один клик.
- **Вход один раз**: сессия хранится в браузере (автообновление токена) до нажатия «Выйти».
- **Дизайн**: стеклянные кнопки-«линзы» с бликом за курсором, плавная смена темы (светлая/тёмная, круговой переход), анимации карточек и окон, адаптивно для телефона (нижнее меню) и ПК (боковое меню). Языки: кыргызский / русский / английский.
- **Установка как приложение**: кнопка «Установить» в шапке (Android/ПК Chrome/Edge); на iPhone — Safari → «Поделиться» → «На экран Домой».

## Локальный запуск
```bash
cp .env.example .env   # заполните и экспортируйте переменные
export $(grep -v '^#' .env | xargs) && node server.js   # http://localhost:3000
```

## Структура
```
server.js            сервер (статика + /api/register, /api/forgot, /api/admin/*)
public/              сайт туристов (/), owner/ (владельцы), admin/ (главный админ), shared/ (общий дизайн и ядро)
supabase/schema.sql  таблицы, RLS, триггеры, realtime, хранилище фото
supabase/seed.sql    демо-данные из шаблона oshrest_demo_v2
scripts/             генерация каталога/seed из шаблона и иконок
```

> Примечание: Render Free «засыпает» после простоя — первый заход может занять ~30–60 секунд.
> Телефоны в демо-данных вымышленные — замените на реальные в панели.
